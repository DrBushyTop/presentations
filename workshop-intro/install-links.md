# Participant links

The static participant page lives in [links/index.html](links/index.html).
It includes the official installation pages, lab challenges, walkthroughs,
sample repositories and sign-in guidance.

Use one short address in the slides: **zure.ly/hack-links**.
The shortlink is live and redirects to the Azure Static Web App.

The page separates tools to install first from tools needed only for specific
tasks. JDK, Maven, Docker, azd, Node.js and PowerShell are conditional.
.NET SDK and Azure CLI remain in the initial setup list.
