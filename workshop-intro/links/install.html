Install your tools

Use the official instructions for your operating system. Keep tools you already have.

VS Code ↗Editor for the lab.GitHub Copilot in VS Code ↗Set up Copilot in your editor.Modernization extension for VS Code ↗The modernization extension supports .NET and Java.Git ↗Clone the samples and save your changes.GitHub CLI ↗Authenticate the modernization agent with gh auth login.GitHub Copilot CLI ↗Use Copilot from your terminal.Modernize CLI quickstart ↗Install and run the modernize terminal tool on Windows, macOS or Linux..NET 10 SDK ↗For the .NET app. Follow the project SDK requirements.Azure CLI ↗Sign in to Azure and select the lab subscription.
Install only when a task needs them JDK, Maven, Docker, azd, Node.js, PowerShell

Check the assessment, build output or deployment plan. Use the SDK versions requested by the project.

OpenJDK ↗For Java builds. Use the JDK version the project needs.Maven ↗If the Java build requires Maven and no usable wrapper is available.Docker Desktop ↗If your task needs local containers. Start Docker after installation.Azure Developer CLI ↗Only for workflows that use azd. Then run azd auth login.Node.js ↗If your chosen install method or an MCP server requires Node.js.PowerShell ↗If your Windows tool installation requires PowerShell.

Reopen your terminal after installation so new commands are available. Modernize CLI and the VS Code modernization extension are separate installations.
